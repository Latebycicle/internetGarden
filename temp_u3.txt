boundary (db) is linear.
If it’s 1D: db is a point
If it's 2D: db is a line
If it’s 3D: db is a plane
If it’s higher D: db is a hyperplane.

Properties of the perceptron learning rule
The perceptron learning rule is guaranteed to converge to a correct solution for any n-dimensional dataset that is
linearly separable.
Meaning: you can have a set of data in any number of dimensions, as long as it is possible to slice it with a line or a
hyperplane. If a correct solution exists, this simple algorithm will find it. Doesn't matter what random perceptron you
start with, it might take a lot of steps, but it's actually guaranteed to converge, which is a really, really powerful result
** Only works for linearly seperable data
